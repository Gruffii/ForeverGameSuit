# Changelog

## 3.5.0 — Foundation Pass

- Added SavedVariables schema/version migration support.
- Centralized round-duration access and formatting.
- Centralized score saving under `FGS.SaveScore` with backward compatibility.
- Added a reusable held-key repeat controller and moved Block-Matrix A/D repeat onto it.
- Kept Options inside the Forever Game Suit hub and grouped them into General, Round, and Maintenance sections.
- Added a runtime addon version indicator to Options.
- Kept all existing game rules, score balance, and native WoW/Forever presentation intact.
